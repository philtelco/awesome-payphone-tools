# awesome-payphone-tools
Cool software for programming of controlling payphones

## Elcotel

- [merkur-xr4ti/Elcotel-Payphone-Network-Manager](https://github.com/merkur-xr4ti/Elcotel-Payphone-Network-Manager) - AI RUST Rewrite of the ancient Elcotel/QuorTech software used to manage Elcotel COCOT Phones -- With added SIP Support.

### Tools

- [Elcotel Custom Firmware Tool](https://payphones.telesfor.org/elcotel-rom/)
- [Elcotel Rate File Creation Tool](https://payphones.telesfor.org/ratefile/)
- [vekejsn/elcotel-playground](https://github.com/vekejsn/elcotel-playground) - reverse engineered rate/configuration files for the Elcotel Series 5 payphones.

### Emulators

- [merkur-xr4ti/Elcotel-Emulator](https://github.com/merkur-xr4ti/Elcotel-Emulator) - A desktop emulator for Elcotel Series 5 "smart" payphones that runs the phone's real firmware.

## Ernest

- [merkur-xr4ti/Ernest-TFW-Telelink-Rewritten](https://github.com/merkur-xr4ti/Ernest-TFW-Telelink-Rewritten) - AI RUST Rewrite of the ancient Telelink software used to manage Ernest COCOT Phones -- With added SIP Support.

## Intracom cardphones

- [vekejsn/intracom-payphones](https://github.com/vekejsn/intracom-payphones/) - mixed resource, reverse-engineering and documentation repository, regarding the Intracom cardphones (INT-100, INT-200, INT-200 GSM, ...)

## Iskra Jatena

- [derp-si/govorilnice-server](https://gitlab.com/derp-si/govorilnice-server) - Original, clean-room, reimplementation of the OMC.

### Original source code

- [derp-si/govorilnice-source](https://gitlab.com/derp-si/govorilnice-source) - Latest source code for the Jatena series of payphones
- [derp-si/govorilnice-omc](https://gitlab.com/derp-si/govorilnice-omc) - Latest source code for the OMC (Operation Management Center) platform for the Jatena payphones

### Related projects

- [vekejsn/modembridge](https://github.com/vekejsn/modembridge) - A dial-up gateway that identifies payphone protocols and bridges modem calls to TCP backends.

## Nortel Millennium

### Managers

- [hharte/mm_manager](https://github.com/hharte/mm_manager) - Manager for the Nortel Millennium series of payphones.
- [jxburros/mm_manager](https://github.com/jxburros/mm_manager) - A SIP-enabled fork of mm_manager, the Millennium Manager by Howard M. Harte. Supports Nortel Millenniums, Elcotel, and Protel phones.
- [vekejsn/mm_manager](https://github.com/vekejsn/mm_manager) - Extension of hharte's mm_manager with support for TTY, TCP ingest, and other small improvements.

### Alternative uses

- [kmatzen/millennium](https://github.com/kmatzen/millennium) - The Millennium Project breathes new life into the Nortel Millennium public telephone by replacing much of its original electronics with modern hardware and software. The project integrates a Raspberry Pi Zero 2 W, two Arduinos, and a VoIP software stack while retaining all the original hardware, including the display, keypad, coin acceptor, magstripe reader, handset, and ringer speaker.

### Tools

- [Millennium Demo Firmware Customizer](https://payphones.telesfor.org/nortel-demo/)

### Documentation & resources

- [muCCC Wiki](https://wiki.muc.ccc.de/millennium:start) - self-explanatory
- [muccc/millennium](https://github.com/muccc/millennium/) - repository with many document resources, firmware dumps, and other utilities.

### Related projects

- [vekejsn/modembridge](https://github.com/vekejsn/modembridge) - A dial-up gateway that identifies payphone protocols and bridges modem calls to TCP backends. Supports the Millennium with [vekejsn/mm_manager](https://github.com/vekejsn/mm_manager) as the backend.
